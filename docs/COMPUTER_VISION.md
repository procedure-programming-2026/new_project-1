# Фоторука — Computer Vision (P1 + P2)

## Про проєкт

Моя частина проєкту відповідає за отримання відео з камери та його обробку мовою C.

У майбутньому програма повинна розпізнавати жести користувача й передавати команди на ESP32 для керування роботизованою рукою.

## P1 — Camera Capture

**Статус: реалізовано та перевірено.**

Для захоплення відео використовується FFmpeg у Windows.

Відео передається через TCP-з'єднання на порт 5000 до програми на C, яка працює в Ubuntu (WSL).

Параметри:
- Роздільна здатність: 640×480.
- Частота камери: 30 FPS.
- Формат захоплення: MJPEG.
- Формат отриманих кадрів: RGB24.

Основні файли:

- `include/stream.h` — опис структури Stream та функцій для роботи з TCP.
- `pc/stream.c` — створення сервера, приймання з'єднання, читання кадрів.
- `pc/stream_test.c` — головна тестова програма.
- `scripts/start.ps1` — автоматичний запуск камери та C-програми.

У проєкті також є початкова реалізація захоплення через V4L2 (`camera.c`, `camera.h`, `main.c`). Вона залишена як експериментальний варіант, оскільки під час роботи з USB-камерою через WSL виникали проблеми із зображенням.

## P2 — Image Processing

**Статус: реалізовано та перевірено.**

Програма аналізує отримані кадри й шукає зелений маркер.

Основна функція:

`find_green_marker(frame, width, height)`

Вона:
1. Перевіряє RGB-компоненти кожного пікселя.
2. Визначає пікселі, де зелений канал переважає.
3. Підраховує кількість знайдених зелених пікселів.
4. Обчислює середні координати X та Y.
5. Повертає результат у структурі Marker.

Структура Marker містить:

- `found` — чи виявлено маркер.
- `x` — горизонтальна координата.
- `y` — вертикальна координата.
- `pixels` — кількість зелених пікселів.

Основні файли:

- `include/image_processing.h`
- `pc/image_processing.c`

Приклад результату:

```text
GREEN MARKER: X=378 Y=345 Pixels=19227
GREEN MARKER: X=516 Y=338 Pixels=18305
Marker not found
```

Наразі алгоритм визначає центр усіх зелених пікселів, а не окремого об'єкта. Це початковий прототип для перевірки обробки зображень.

## Запуск

Для поточної конфігурації потрібні Windows, WSL Ubuntu, GCC, Make, FFmpeg та камера.

Компіляція в Ubuntu:

```bash
cd ~/new_project-1/pc
make
```

Автоматичний запуск виконується через `scripts/start.ps1` у Windows PowerShell.

У скрипті використовується камера `ACER HD User Facing`. Для іншої камери потрібно змінити її назву.

Для зупинки — Ctrl+C.

## Що вже перевірено

- Безперервне отримання відеокадрів.
- Автоматичний запуск FFmpeg і TCP-приймача.
- Розпізнавання зеленого предмета.
- Зміна координат X та Y під час переміщення предмета.
- Відсутність виявлення, коли маркера немає.

## Що потрібно узгодити для інтеграції

Наступні модулі перетворюватимуть дані про положення або рух маркера на команди для ESP32.

Нам потрібно спільно визначити:

- Як комп'ютер буде з'єднуватися з ESP32.
- Який формат команд використовуватимемо.
- Як ESP32 підтверджуватиме отримання команд.
- Якою буде поведінка маніпулятора при втраті маркера або з'єднання.

Поки що P1 та P2 не надсилають команд на ESP32.
